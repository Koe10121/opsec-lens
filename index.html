Your images never leave your browser: nothing is uploaded, and all detection runs on this device.

Drag on the image to add a box by hand. Tick or untick findings on the right. The download is re-encoded from the canvas, which strips EXIF metadata (location, camera, etc.).

Findings

      What does it blur?

      Anything that could point to a person, a machine, or a way in. It reads the text in your screenshot (OCR), then checks it against these rules.

      Network

      • Public IP addresses, with the owning organisation when known
      • Internal IPs (10.x, 172.16-31.x, 192.168.x)
      • IPv6 addresses
      • Internal hostnames and URLs (.internal, .local, .corp, .lan, .test)

      Contact

      • Email addresses
      • Phone numbers (international, (202) 555-0143 style)

      Secrets

      • API keys like sk_..., ghp_..., xox...
      • Bearer tokens
      • Long random strings (high-entropy, lower confidence)

      Table columns

      • If a header says Source IP, Username, Host, Email… the whole column below is covered, even values that match no pattern

      Thai data

      • National ID (13 digits, check digit verified)
      • Thai phone numbers
      • Student IDs next to a label
      • Names after นาย / นาง / นางสาว (best effort)

      Faces & QR codes

      • Faces, found by a small model running on your device
      • QR codes

      Detection is not a guarantee. Always review every box, and check the image yourself, before sharing.

      Not covered: licence plates, handwriting, names in English, and anything the OCR cannot read. Add those by hand with + Add box or by dragging on the image.
