# 001: Tracer: drop image → OCR → email boxes → download

- type: AFK
- blocked_by: none
- PRD: 000-prd-opsec-lens.md

## What to build
The thinnest end-to-end path. Scaffold the project (Vite + vanilla TypeScript, Vitest, `npm test`,
`npm run typecheck`). Page with a dropzone for a PNG. Run Tesseract.js (English) in the browser behind
an `ocr.recognise(image, {langs}) → Word[]` interface. Define `Word`, `Finding`, `Detector` and
`runDetectors` in `detectors/types`. Add an email detector in `detectors/contact`. Draw a box over each
finding on a canvas. A "Download" button exports the image with solid boxes over the findings
(`redact.apply(image, findings, 'solid') → Blob`).

## Acceptance criteria
- `npm run dev` serves a page; dropping a synthetic PNG containing `user@example.com` shows a box over it.
- Download produces a PNG where the email's pixels are covered by a solid box and the rest is unchanged.
- Email detector has unit tests on hand-built `Word[]` fixtures (positives, negatives).
- `redact` has a test asserting pixels under the box change and pixels outside do not.
- `npm test` and `npm run typecheck` pass.
- Test image is synthetic and generated by a script in the repo (example.com only).
- No network calls carry image data or text.
