## What to build
Deploy the static Vite build to Vercel. Add a "Try it" button that loads a synthetic sample
screenshot (generated by a script in this repo, documentation-range IPs and example.com only). Add
a visible "images never leave your device" notice and a "detection is not a guarantee, always review"
notice. Clear messages for no findings and OCR failure. Add a Playwright e2e test asserting no network
requests are made while an image is processed. Host Tesseract language data from the app's own
origin. Add COOP/COEP headers only if WASM threading needs them.

## Acceptance criteria
- Public Vercel URL works; "Try it" shows boxes in under 10 seconds.
- Both notices are on the page.
- No-network e2e test passes in CI/locally.
- No third-party CDN requests for models or traineddata.
- Test/sample data uses only documentation ranges and example.com/.test.
- `npm test` and `npm run typecheck` pass.
