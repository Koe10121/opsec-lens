# OpSec Lens

Browser tool that finds and blurs what makes a screenshot unsafe to share. See brief.md.

- Work in vertical slices: every change should be visible and testable end to end.
- Use TDD (red, green, refactor) for detector and redaction logic. Run `npm test` and `npm run typecheck` before committing.
- Prefer a few deep modules with small interfaces (one per detector family) over many tiny files.
- PRIVACY RULES (non-negotiable):
  - User images never leave the browser. No network calls with image data or extracted text.
  - Never commit real screenshots containing real people, real organisations' IPs/hostnames, or real IDs.
    All test and benchmark data is synthetic and generated by scripts in this repo.
  - Use documentation ranges for example IPs (192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24) and example.com/.test domains.
